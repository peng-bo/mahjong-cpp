# Rewrite as MCR-only

We will rewrite the library for Chinese Official Mahjong / MCR rather than preserving Japanese riichi mahjong as a parallel ruleset. The existing public model is deeply shaped by riichi-only concepts such as riichi, dora, ura dora, red dora, fu, honba, kyotaku, and limit-hand score titles; keeping both rulesets would make the MCR design harder to reason about and maintain.
